# Release Notes — v0.0.7 (2026-08-13)

## ✨ New Features

- **Local authentication provider**: Konfigo now supports a self-contained, cookie-based local auth provider as an alternative to external identity providers (e.g. SAML/OIDC).
  - New `local_users` storage layer (Postgres) with PBKDF2 password hashing (`PasswordHasher`).
  - New endpoints for managing local users (create, update, delete) via `LocalUsersController`.
  - New login flow (`LocalLoginRequest`) and admin user auto-seeded on startup.
  - Frontend: new **Users** management page, updated login page, and auth store/API client support for the local provider.
  - New docs section covering local auth setup (`docs/authentication.md`).

## 🔧 Improvements

- **Auth**: JWT/cookie identities now use the configured `RoleClaimType` from `KonfigoAuthenticationOptions` instead of a hardcoded `ClaimTypes.Role`, so role-based authorization respects your configured claim mapping.
- **Docker/CI**: Image tagging strategy updated — `latest` is no longer applied via `flavor`-based logic, and the `{major}.{minor}` tag pattern was dropped in favor of full semver + `latest` tags only, giving cleaner and more predictable image tags.
- **Backend**: Added `Microsoft.OpenApi` package reference to support OpenAPI document generation.

## 📦 Other

- Version bumped to `0.0.7` across `VERSION`, `Version.props`, backend/frontend project files, and documentation.
